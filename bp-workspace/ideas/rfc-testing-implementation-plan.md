## Testing Implementation Plan

### Goal

Implement automated testing infrastructure for counter_app to prevent regressions and enable confident refactoring.

### Scope

**Phase 1 (Essential — Week 1):**
- Vitest + React Testing Library setup
- Unit tests for core logic: `useCountdown` hook
- Component test: `CountdownTimer`
- Auth tests: `lib/auth.ts`

**Phase 2 (Important — Week 2):**
- Playwright E2E setup
- E2E: Login flow (existing user + auto-registration)
- E2E: Admin dashboard access

**Phase 3 (Nice-to-have — Week 3+):**
- Tests for individual counter variants
- i18n tests (next-intl)
- Coverage reporting

### Technical Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Test Runner | Vitest | Native ESM, 2-3x faster than Jest, zero config with Next.js |
| Component Testing | React Testing Library | Industry standard, focuses on user behavior |
| E2E | Playwright | Better DX than Cypress, parallel execution |
| Coverage | v8 (native) | Built-in to Vitest, accurate |
